# Классификатор комментариев

## Назначение приложения
Веб-сервис для автоматического анализа тональности пользовательских отзывов с классификацией текстов на **положительные** и **отрицательные** категории. 

Приложение предоставляет авторизованным пользователям возможность:
- Отправлять комментарии на анализ и получать мгновенную оценку тональности.
- Сохранять историю всех выполненных проверок в своей учетной записи.

## Необходимые экраны
1. **Экран аутентификации (Вход/Регистрация)**
2. **Главный экран (Классификатор)**
3. **Экран истории запросов (Профиль)**

## Пользовательские сценарии
1. **Регистрация и доступ:** Анонимный посетитель открывает сайт и видит экран входа, создает аккаунт, авторизуется и только после этого получает доступ к главному экрану.
2. **Проверка отзыва и сохранение:** Авторизованный пользователь вставляет текст комментария в поле на главном экране и жмет кнопку. Приложение показывает результат классификации на экране, "под капотом" текст и результат отправляются на бэкенд для сохранения в БД.
3. **Просмотр старых проверок:** Пользователь открывает раздел "История" и видит таблицу со всеми своими прошлыми запросами, приложение при этом следит, чтобы он видел только свои запросы, а не чужие.
